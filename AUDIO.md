# Бесплатная немецкая озвучка

Piper синтезирует предложения локально на CPU голосом `de_DE-thorsten-high`.
После первой установки и загрузки модели интернет не нужен. API-ключей, подписки
и оплаты за символы нет. Генерация требует времени и ресурсов компьютера.

## Запуск в Windows

Из корня этого репозитория (нужен Python 3.12):

```powershell
powershell -ExecutionPolicy Bypass -File tools/generate-audio.ps1
```

Команда создаёт отдельное окружение `.venv-audio`, устанавливает зависимости,
загружает голос в `.audio-models` и создаёт записи. Уже установленные компоненты
не скачиваются повторно. Для продолжения после остановки используйте ту же команду.

Первые 20 уникальных текстов для оценки голоса:

```powershell
powershell -ExecutionPolicy Bypass -File tools/generate-audio.ps1 -Limit 20
```

Проверка полноты, SHA-256 и декодирования всех MP3 без повторного синтеза:

```powershell
powershell -ExecutionPolicy Bypass -File tools/generate-audio.ps1 -VerifyOnly
```

## Результат

- `audio/de-DE/*.mp3`: отдельный файл на уникальное полное предложение; mono, 64 kbit/s.
- `audio/de-DE/manifest.json`: сопоставление ID упражнения, текста, перевода и MP3.
- `audio-preview.html`: поиск и прослушивание с выбором скорости.
- `.audio-cache`: контрольные суммы, длительности и данные для возобновления.
- `audio-preparation/verification.json`: результат декодирования всех MP3 и проверки покрытия колоды.

Для прослушивания:

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

Открыть <http://127.0.0.1:8765/audio-preview.html>.

Колода `assets/assets/deck/A1.json` читается заново при каждом запуске. В каждом
контексте `___` заменяется полем `answer`, в заданиях на выбор — `correct`.
В текущей колоде 2658 упражнений и 2650 уникальных полных предложений.
Варианты `alsoAccepted` не озвучиваются отдельно. Англоязычные банки грамматики
и диагностики не включаются в немецкую озвучку.

Имена MP3 зависят от текста, модели, её конфигурации, версий синтезатора и кодировщика,
темпа и параметров кодирования. Изменившиеся тексты получают новые записи.
Незавершённые файлы записываются с расширением `.part`; повреждённые MP3
обнаруживаются по SHA-256 и пересоздаются. Устаревшие MP3 автоматически не удаляются.
Одинаковые предложения используют одну запись. По умолчанию работает до четырёх
процессов, каждый с одним потоком ONNX; модель загружается один раз на процесс.

Для настройки ресурсов или темпа:

```powershell
.venv-audio/Scripts/python.exe tools/generate_audio.py --workers 2 --threads 1 --length-scale 1.08
```

Чем больше `length-scale`, тем медленнее речь. Изменение темпа создаст новый набор
файлов. Увеличение количества процессов повышает расход памяти.

Тесты обработки текста и восстановления после повреждения:

```powershell
.venv-audio/Scripts/python.exe -m unittest discover -s tools -p test_generate_audio.py
```

## Подключение к приложению

Готовые записи и каталог можно размещать рядом со сборкой. Для конкретного
упражнения нужно найти `entries[].id` в `manifest.json` и воспроизвести
`audio/de-DE/` + `entries[].file`. До проверки ответа полное предложение может
раскрывать решение; в интерфейсе тренировки лучше показывать кнопку после ответа.

Записи подключены к существующим кнопкам Flutter через `recorded-speech.js`.
При запуске страницы небольшой `audio/de-DE/playback-index.js` загружается перед
Flutter, поэтому первое нажатие не ждёт скачивания большого каталога. MP3 загружаются
по одному при воспроизведении. Адреса учитывают базовый путь `/verbalingo-deutsch/`.

Адаптер воспроизводит запись при точном совпадении полного немецкого предложения
(с нормализацией пробелов и Unicode). Для отдельных слов, альтернативных ответов
и неизвестных текстов используется прежний браузерный TTS. Если MP3 недоступен или
браузер блокирует воспроизведение, адаптер также возвращается к браузерному TTS.
Голос готовых записей всегда Thorsten; настройка голоса в приложении относится
к браузерному синтезатору. Пауза, продолжение, повтор и отмена связаны с состоянием
Flutter. Немецкая озвучка доступна даже без установленного немецкого системного голоса.

Исходников Dart в репозитории нет, поэтому `tools/install_site_audio.py` делает
семь проверяемых замен в веб-сборке: шесть вызовов управления звуком и проверку
доступности немецкого языка. Глобальный `window.speechSynthesis` не изменяется.
Это совместимость с текущей сборкой, а не изменение исходного Dart-проекта.

После новой сборки Flutter или изменения набора аудио:

```powershell
.venv-audio/Scripts/python.exe tools/install_site_audio.py
```

Основная команда генерации запускает этот шаг автоматически после проверки MP3.
Установка повторяема; если структура новой Flutter-сборки отличается, скрипт
останавливается с ошибкой до записи изменённого JS. В таком случае нужно обновить
соответствия в `HOOKS` или перенести интеграцию в исходный Dart-код.

Тестирование адаптера:

```powershell
node --test tools/test_recorded_speech.cjs
```

## Подсказка для A1

В задании «Припоминание с подсказкой» кнопка «Подсказка — перевод предложения»
показывает `translation` текущего контекста целиком, включая текст в скобках.
Перевод появляется только после нажатия; слово на немецком остаётся пропущенным.
Учёт использования подсказки и проверка ответа сохранены. Этот фикс также
повторно устанавливается `tools/install_site_audio.py` (ещё две проверяемые замены).

`node --test tools/test_sentence_hint.cjs` проверяет настоящий скомпилированный
рендерер задания с изолированными UI-примитивами, без записи учебного прогресса.
